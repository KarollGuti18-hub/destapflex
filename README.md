# DestapFlex — Portafolio Digital

Portafolio digital académico de **DestapFlex**, construido con Next.js (App Router), TypeScript y Tailwind CSS.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm start
```

## Recursos originales

Los archivos originales se conservan en:

- `Logo/`
- `Renders/`
- `VSM/`
- `Lean Canvas/`
- `Textos/`
- `Bitacora/`
- `Video/`

Las copias con nombres seguros para la web están en `public/assets/`.
